# 작업 전 확인 질문 (도서별 인테이크)

원고마다 대사 표기와 레이아웃이 다르다. **코드를 돌리기 전에** 아래를 묻고
답을 `<원고>_작업설정.json`에 기록한다. 이 파일이 있으면 이후 실행에 자동 반영되고,
AI 프롬프트에도 주입되어 판단 품질이 올라간다.

한 번에 다 묻지 말고, 원고를 먼저 3~5쪽 훑어본 뒤 **모르는 것만** 묻는다.
훑어보면 알 수 있는 건(따옴표 스타일 등) 묻지 말고 직접 확인한다.

---

## 질문 목록

### 1. 이 원고에서 대사는 어떻게 표기돼 있나요?
- **큰따옴표로 다 감싸져 있다** → `label_mode: "quote"` (기본)
- **대사가 대시(-)로 시작한다(따옴표 없음)** → `label_mode: "dash"`
- **따옴표 + 대시가 섞여 있다** → `label_mode: "mixed"`
- **따옴표 없이 서술 속에 섞여 있다** → `label_mode: "narrative"`
- **원고에 화자 이름이 이미 인쇄돼 있다(희곡·대본형식)** → `label_mode: "highlight-only"`
  (라벨을 새로 달지 않고 하이라이트만. 이름을 또 달면 지저분해진다)

> `dash` / `mixed`는 대시로 시작하는 대사(`- 더 보고 싶다고 하면요?`)를 **결정적 코드가
> 직접** 잡는다. AI에 의존하지 않아 놓치지 않는다. 대사가 다음 줄로 이어지면 함께 흡수한다.
> `narrative` / `mixed`는 서술 속에 따옴표·대시 없이 섞인 대사를 AI가 지목하고, 코드가
> 그 문구가 원고에 실제로 있는지 확인한 것만 채택한다(지어낸 문구 자동 폐기).
> 화자는 그 항목 안의 `speaker`로 배정된다(`output-rules.md` 3-D).

### 1-A. 주 따옴표 말고 다른 기호로도 대사를 적나요? (보조 따옴표)
예: 큰따옴표는 발화, 작은따옴표(‘’)는 무전·회상 속 대사. 그런 책이면 →
`extra_quote_pairs: ["‘’"]` (여는 기호와 닫는 기호를 붙여 문자열 하나로. 여러 쌍이면 항목을 늘린다).
강조(사람‘들’)·별명 인용(‘촉새끼’)과 구분하기 위해 코드는 **그 줄 전체를 차지하는 것만** 대사로
보고, 안쪽 글자 수가 `extra_quote_min_len`(기본 7) 미만이면 강조로 보고 제외한다.
기본은 비어 있음 — 대부분의 책은 필요 없다. (v2.4에서 문서화. 코드에는 이전부터 있었다.)

### 2. 도서 유형은?
그림책 / 어린이문학 / 청소년 / 일반문학 / 논픽션 / 에세이 / 학습서
→ `book_type`. 캐스팅 관례(아동은 여성 성우)와 음향 밀도 판단에 쓰인다.

### 3. 이 원고만의 특이점이 있나요?
예: 사투리 인물, 외국인 캐릭터, 시점이 중간에 바뀜, 회상이 잦음,
노래·시 낭송 구간, 화자가 여럿인 편지글, 각주가 본문에 섞임,
같은 인물이 아동기→노년기로 등장
→ `special`. **여기 적힌 내용은 AI 프롬프트에 그대로 들어간다.**

### 4. 출판사 요청사항이 있나요?
예: 특정 인물 성별 지정, 발음 지정, 특정 구간 제외
→ `publisher_note`

### 5. 음향 방향은?
예: 음악 최소·앰비언스 위주 / 씬마다 확실히 / 효과음 없이 BGM만
→ `sound_direction`. 없으면 비워둔다(기본 밀도로 제안).

### 6. (성우별 대본이 필요할 때) 성우 구성
기본은 `actors: "auto"` — **코드가 대본을 분석해 필요한 인원과 배역별 성별을 정한다.**
대표가 인원을 미리 정해 뒀다면(예: 메인1+서브3) 숫자 `4`를 넣는다. 규칙은 `casting.md`.
※ 대표가 "여자 메인 1명"처럼 **메인 성우 성별**을 지정하면, 대사가 가장 많은 인물의 성별과
   맞는지 확인한다. 다르면 `_캐스팅.json`에서 메인↔해당 서브의 `characters`를 통째로 맞바꾼다
   (색은 배역 고정이므로 색은 그대로 둔다).

### 6-A. 한 지면에 단이 둘 이상인가? (그림책·펼침면 조판)
펼침면 한 장에 좌우 두 쪽이 들어 있거나 단이 나뉘어 있으면 → `reading_order: "columns"`.
PDF가 내놓는 블록 순서가 읽는 순서와 달라, 단 끝에서 열린 따옴표가 같은 지면에서 닫히는데도
'안 닫혔다'고 보고 **다음 쪽 문장을 끌어다 붙인다**(서로 다른 화자의 대사가 한 덩어리가 된다).
판단법: `--detect-only` 로그의 `[감지] … (페이지 걸침 N건)`이 유난히 많거나, 검수 CSV의
대사에 쪽번호 숫자가 섞여 있으면(`…누구로 대결6362하지?`) 이 설정을 켠다.
※ 이미 판단이 끝난 원고에서 이 값을 바꾸면 대사 id가 밀린다. 반드시 **대사 텍스트 기준으로
   기존 배정을 재매핑**한 뒤 쓸 것.

### 7. (그림책·삽화 많은 책일 때) 여백 처리
삽화가 페이지를 꽉 채우면 메모 놓을 자리가 없다. 기본은 `gutter: "auto"`로,
자리가 없을 때만 페이지 오른쪽에 흰 띠를 덧대 거기에 놓는다.
원본은 이동·축소 없이 그대로 유지되므로 무손상이다.
- 여백띠를 절대 원하지 않으면 `"off"` (대신 못 놓은 메모는 CSV·브리핑에만 남는다)
- 폭을 직접 지정하려면 숫자(pt). 기본 150.

## 작업설정 파일 예시

```json
{
  "book_type": "어린이문학",
  "dialogue_style": "큰따옴표 + 일부 서술형 대사",
  "speaker_shown": "아니오",
  "label_mode": "mixed",
  "extra_quote_pairs": [],
  "extra_quote_min_len": 7,
  "special": "형수는 과잉행동장애 아동. 아담은 대사가 거의 없고 침묵이 연출 포인트. 5학년 회상 구간이 p36~p40.",
  "publisher_note": "아이들 이름 발음은 표준 한국어로",
  "sound_direction": "학교 생활음 위주, 회상 구간만 음악",
  "gutter": "auto",
  "actors": 3,
  "reading_order": "page",
  "font": "",
  "model": ""
}
```

`--init`이 만드는 템플릿에 위 키가 전부 들어 있다. `font`·`model`은 원고가 아니라 **컴퓨터별** 설정이다:
- `font` — 한글 폰트 파일 경로. 비우면 자동 탐색(`.env`의 `SP_KFONT` → 스킬 `assets/fonts/` → 시스템).
  못 찾으면 렌더가 중단된다(`references/setup.md`).
- `model` — 판단 모델 ID. 비우면 `.env`의 `SP_MODEL` → 코드 기본값. 코드를 고치지 않고 바꾸는 길이다.

## 물어보지 않아도 되는 것

- 따옴표 스타일(“” / "" / 「」) — 코드가 빈도로 자동 판별한다
- 페이지 수·대사 수 — `--detect-only`로 무료 확인 가능
- 폰트 깨진 페이지 — 실행 시 `[진단]`에 자동 출력된다

## 물어본 뒤 반드시 할 것

`--detect-only`를 먼저 돌려 감지된 대사 수를 사용자에게 보여준다.
숫자가 원고 체감과 크게 다르면 label_mode를 잘못 잡은 것이다.

`narrative`/`mixed` 책은 판단 뒤 `--check`에서 **따옴표 없는 대사의 채택/폐기 건수**를 본다.
폐기(원고에 없는 문구)가 많으면 AI가 anchor를 요약한 것이니, 원문 그대로 고쳐 다시 `--check`한다.
