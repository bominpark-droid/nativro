# 성우 캐스팅 & 마스터 대본

특히 소설처럼 서브 성우가 있는 경우, **모든 성우의 파트를 색으로 구분한 1장짜리 마스터
대본**을 만든다. 성우별 개별 PDF를 여러 장 뽑지 않고, 하나의 전체 대본에 색으로 표시한다.

## 성우별 색 (고정)

| 배역 | 색 |
|---|---|
| 메인 | 노랑 |
| 서브1 | 하늘색 |
| 서브2 | 연보라 |
| 서브3 | 핑크 |
| 서브4 | 초록 |

각 대사가 담당 성우 색으로 칠해져, 어느 성우 파트인지 한눈에 보인다.
캐릭터 이름 라벨(검정 글씨 + 그 성우 색 배경)도 대사 옆에 함께 표시된다.

## 배정 규칙 (2026-08-02 대표 확정 — 이 순서로 판단한다)

0. **한 성우는 한 성별만 (절대).** 어린이·여자 역할 → 여성 성우, 남자 역할 → 남성 성우.
   한 배역에 남녀를 섞지 않는다. **남성 서브에 여자·어린이·아줌마 배역을 넣지 않는다.**
   성별이 본문에 안 나오는 캐릭터도 `gender_suggest`(연기 기준 제안 성별)를 반드시 채워
   판단한다 — 이걸 비워 두면 여성 메인에 악당 상어가, 남성 서브에 아줌마가 섞인다.
1. **메인에 최대한 몰아준다.** (핵심 — 비용이 여기서 갈린다)
   - 티키타카가 **아닌** 대사 → 메인.
   - 티키타카라도 **나이 구간이 달라 톤이 구별되면** → 메인.
     (20대 여성 ↔ 60대 여성 O, **어린이 ↔ 성인 O**. 20대 ↔ 30대 같은 구간이면 X)
   - 나이 구간이 같아도 **잠깐 나오는 씬**(주고받은 횟수 < `ADJ_MIN`=3)이면 → 메인.
   - **대사가 아주 적은 단역**(≤ `MINOR_MAX`=5)은 티키타카가 있어도 나누지 않는다.
     지문이 매번 누구인지 밝혀 주므로 한 성우가 톤을 갈라 소화한다.
2. **서브로 빼는 경우** — ①메인과 성별이 다른 캐릭터 ②같은 성별인데 나이 구간까지 같아
   구별이 안 되면서 계속 주고받는 경우.
3. 나이 구간: 어린이 / 10대 / 젊은성인(20~30대) / 중년(40~50대) / 노년(60+) / 성인(나이 불명).
   숫자 나이('3세 남짓')와 '성인'도 구간으로 읽는다 — 이걸 못 읽으면 어린이와 어른조차
   구별 못 해 성우가 불필요하게 늘어난다.
4. 서로 직접 대화하지 않는 인물(A-B, 나중에 A-C)은 B·C가 비슷해도 한 성우로 커버 가능.

**성우 수와 성별은 코드가 정한다.** `_작업설정.json`의 `actors`를 `"auto"`(기본)로 두면
위 규칙을 전부 지킬 수 있는 **최소 인원**을 찾아 배역별 성별까지 확정한다.
숫자를 직접 넣으면 그 인원으로 맞춘다(인원이 모자라면 규칙이 깨지므로 경고를 확인할 것).

**배역 이름에는 성별을 함께 쓴다** — `메인(여)`, `서브1(남)`, `서브2(여)`.
표지 범례·로그·캐스팅 요약 전부 이 표기를 쓴다.

## 절차

```bash
# 1) 전체 작업으로 _AI판단.json 을 먼저 만든다 (인물·화자 배정 확보)
python3 scripts/sp_pipeline.py "원고.pdf"

# 2) 캐스팅 제안 받기 -> _캐스팅.json 생성 + 요약 출력
python3 scripts/sp_pipeline.py "원고.pdf" --cast-suggest

# 3) _캐스팅.json 을 열어 검토·수정 (캐릭터를 배역에 재배치)
#    출력된 '주고받는 대화가 잦은 쌍'을 참고한다.

# 4) 승인된 캐스팅으로 1장짜리 마스터 대본 생성
python3 scripts/sp_pipeline.py "원고.pdf" --master
```

성우 수는 `_작업설정.json`의 `actors`로 지정한다(메인 포함, 최대 5 = 메인+서브4).
`"auto"`(기본)면 코드가 규칙을 지킬 수 있는 최소 인원을 스스로 정한다.

## _캐스팅.json 형식

```json
{
 "메인":  {"color": [1.0, 0.92, 0.23], "gender": "여", "characters": ["지민", "엄마", "노인"]},
 "서브1": {"color": [0.53, 0.81, 0.98], "gender": "남", "characters": ["현우"]}
}
```

`gender`는 그 배역을 맡을 **성우의 성별**이다. 표지 범례에 `서브1(남)`으로 나온다.

- `characters`에 캐릭터 이름(= _AI판단.json 의 화자 이름)을 넣는다.
- 어느 배역에도 없는 캐릭터가 있으면 `--master` 실행 시 **경고**가 뜨고, 그 대사는
  회색으로 칠해진다. 반드시 배정한다.
- 색은 위 고정값을 유지하는 게 좋다(성우들이 익숙해진 색).

## 마스터 대본 구성

`<원고>_마스터대본.pdf`:
- 표지: **색 범례**(어느 색이 어느 성우·어떤 캐릭터인지) + **★ 확인 필요 대사 목록**
- 본문: 모든 대사가 담당 성우 색으로 칠해짐 + 캐릭터 이름 라벨(이름 앞 (성별,나이)).
  **음향 씬 카드(보라색)도 항상 함께** 들어간다 — 따로 지시하지 않아도 페이지/2~3문단마다.
  내레이션(대사 아닌 부분)은 칠하지 않음(= 메인 성우가 읽음).
- **원본과 기존 메모(주석)는 그대로 보존**된다(어떤 경우에도 지우거나 고치지 않음).

## 중요

- **라벨 정합성 주의**: `--master`는 실행 시점에 대사를 다시 감지한다. `_작업설정.json`의
  `label_mode`가 전체 작업 때와 같아야(예: dash 책은 계속 dash/mixed) 배정과 대사가 맞는다.
- **★ 확인 필요**: 화자 배정이 불확실한 대사는 색을 칠하되 표지의 ★ 목록에 올린다.
  녹음 전 그 대사만 검수한다.
- **`--cast-suggest`·`--master`는 판단 캐시만 쓴다.** `_AI판단.json`이 없으면 API를 부르지 않고
  안내문을 내며 중단한다(v2.4 — 이전엔 캐시가 없으면 작품 분석·화자 배정·음향까지 전부 과금된 뒤에야
  캐스팅으로 넘어갔다).
- **`label_mode: "highlight-only"` 책은 마스터 대본에도 라벨을 달지 않는다**(v2.4). 색만 칠한다.
- 캐스팅 요약의 '주고받는 대화가 잦은 쌍'에서 **단역(대사 ≤ 5)은 경고 대상이 아니다** — 규칙 1대로
  한 성우가 톤을 갈라 소화한다. `(같은 성우 — 단역이라 …)`로 표시된다(v2.4).
